# Fire Tasks / Agent handoff
> Give the agent a clear job. Keep the person in control.

## Review the task
- Read the request, its context and the source.
- Check the goal and the agent's available capabilities.

## Choose a route
### 1. A basic task
- [x] Review notes, draft questions, or prepare a reply.
- Prepare the output for the user to review.

### 2. More context or another tool
- Assess complexity, scope and the required `MCP` connection.
- **Ask questions** when context or access is missing.
- Use the answers to refine the plan before acting.
- Example: draft a **Miro board** from an agreed brief.
- Keep those answers with the task for the next attempt.

### 3. The agent cannot take it on
- [ ] Leave the task for the user to complete.
- Explain what needs their judgement or input.

---
## Hand the work back
- Show the output, sources and any assumptions.
- Keep the original task **open**.
- Let the user review, edit and manually mark it complete.
